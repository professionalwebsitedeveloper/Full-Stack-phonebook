# Phonebook Backend

This is a simple phonebook backend application built with Node.js and Express. It allows users to manage a list of contacts, including creating, reading, updating, and deleting entries.

## Features

- Add new contacts
- View all contacts
- Update existing contacts
- Delete contacts

## Getting Started

### Prerequisites

- Node.js (version 14 or higher)
- npm (Node package manager)

### Installation

1. Clone the repository:
   ```
   git clone <repository-url>
   ```
2. Navigate to the project directory:
   ```
   cd phonebook-backend
   ```
3. Install the dependencies:
   ```
   npm install
   ```

### Running the Application

To start the application, run:
```
npm start
```
The server will start on `http://localhost:3000`.

### API Endpoints

- `GET /api/persons` - Retrieve all contacts
- `POST /api/persons` - Add a new contact
- `PUT /api/persons/:id` - Update an existing contact
- `DELETE /api/persons/:id` - Delete a contact
